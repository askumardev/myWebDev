JavaScript Interview Questions and Answers

Note
Use this page as a quick reference for common JavaScript interview topics and short explanations you can review before an interview.
1. What is JavaScript?
JavaScript is a lightweight, interpreted programming language used to make web pages interactive.
2. What is the difference between let, const, and var?
var is function-scoped and can be reassigned; let is block-scoped and can be reassigned; const is block-scoped and cannot be reassigned.
3. What is hoisting?
Hoisting means declarations are moved to the top of their scope during execution, but initialization remains in place.
4. What is a closure?
A closure is a function that remembers variables from its outer scope even after that scope has finished executing.
5. What is the difference between == and ===?
== compares values after type coercion, while === compares both value and type.
6. What is the DOM?
The DOM is the Document Object Model, which represents HTML elements as objects that can be manipulated with JavaScript.
7. What is an arrow function?
An arrow function provides a shorter syntax for writing functions and does not have its own this binding.
8. What is a promise?
A promise represents the eventual completion or failure of an asynchronous operation.
9. What is async/await?
async/await is syntax that makes asynchronous code easier to read and write by using promises in a more synchronous style.
10. What is the difference between map and forEach?
map creates a new array with the results, while forEach just iterates and does not return a new array.
11. What is event bubbling?
Event bubbling means an event starts from the target element and moves upward through its parent elements. This helps in handling events efficiently.
document.querySelector('.parent').addEventListener('click', () => {
  console.log('Parent clicked');
});

document.querySelector('.child').addEventListener('click', () => {
  console.log('Child clicked');
});
12. What is the difference between synchronous and asynchronous code?
Synchronous code runs line by line, while asynchronous code allows other tasks to continue while waiting for a result.
console.log('Start');

setTimeout(() => {
  console.log('Later');
}, 1000);

console.log('End');
13. What is destructuring?
Destructuring allows you to unpack values from arrays or objects into variables in a concise way.
const user = { name: 'Asha', age: 22 };
const { name, age } = user;

console.log(name); // Asha
console.log(age); // 22
14. What is the spread operator?
The spread operator expands an iterable into individual elements, which is useful for copying arrays or combining values.
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];

console.log(arr2); // [1, 2, 3, 4, 5]
15. What is the difference between null and undefined?
undefined means a variable has been declared but no value assigned yet. null is an intentional empty value.
let a;
let b = null;

console.log(a); // undefined
console.log(b); // null
16. What is the difference between shallow copy and deep copy?
A shallow copy copies the top level of an object, while a deep copy duplicates nested objects too.
const person = { name: 'Ravi', address: { city: 'Delhi' } };
const shallowCopy = { ...person };

shallowCopy.address.city = 'Mumbai';
console.log(person.address.city); // Mumbai
17. What is array reduce used for?
reduce is used to iterate through an array and accumulate a single result such as a sum or object.
const numbers = [1, 2, 3, 4];
const total = numbers.reduce((sum, num) => sum + num, 0);

console.log(total); // 10
18. What is the this keyword?
The this keyword refers to the object that is currently executing the function, depending on how the function is called.
const user = {
  name: 'Nina',
  greet() {
    console.log(this.name);
  }
};

user.greet();
19. What is a callback function?
A callback function is a function passed as an argument to another function and executed later.
function greet(name, callback) {
  callback(name);
}

greet('Sam', (name) => {
  console.log('Hello ' + name);
});
20. What is the difference between function declaration and function expression?
A function declaration is hoisted and can be used before it is defined, while a function expression is created at runtime and is not hoisted in the same way.
sayHello();

function sayHello() {
  console.log('Hello from declaration');
}

const greet = function() {
  console.log('Hello from expression');
};

greet();
