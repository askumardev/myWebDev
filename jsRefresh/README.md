# JavaScript Refresh

This folder contains beginner-friendly JavaScript practice files grouped by topic for learning and revision.

## What you will learn

- Variables and data types
- Functions and arrow functions
- Arrays and array methods
- Objects and closures
- Hoisting and this keyword
- Promises, async/await, and the event loop
- DOM manipulation and events
- Fetch API, storage, modules, and OOP
- Functional JavaScript, performance, and design patterns
- Common interview questions and answers

## How to use these files

1. Open any HTML file in a browser.
2. Read the note section at the top of the page.
3. Study the JavaScript example linked from the page.
4. Modify the code in the JS file and refresh the browser to test your understanding.

## JavaScript notes

- Use let for values that may change and const for values that should stay fixed.
- Prefer modern syntax such as arrow functions and template literals.
- Understand how scope, closures, and this work in JavaScript.
- Practice asynchronous programming with promises and async/await.
- Learn DOM manipulation to make websites interactive.
- Review array methods like map, filter, reduce, and find regularly.

## Suggested learning order

1. Start with variables and functions.
2. Move to arrays and objects.
3. Learn closures, hoisting, and this.
4. Practice promises and async/await.
5. Explore the DOM, events, and fetch.
6. Finish with modules, OOP, performance, and interview questions.
